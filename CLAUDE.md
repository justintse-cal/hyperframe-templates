# HyperFrames Composition Project

This project's agent instructions live in [`AGENTS.md`](./AGENTS.md), and the
design system lives in [`design.md`](./design.md). Read both before touching a
frame.

`AGENTS.md` is the single source of truth for the workflow, commands, project
structure, the slug-id scheme, the template groups, and linting. This file is
deliberately a pointer — it used to duplicate `AGENTS.md` and drifted out of date
(25 templates, a deleted letter scheme, the old warm-gradient design), so the
duplicate was removed rather than kept in sync.

Nothing here overrides `AGENTS.md` or `design.md`.
